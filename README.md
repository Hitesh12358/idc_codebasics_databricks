# Databricks 14 Days AI Challenge 🚀

This repository documents my learning journey and hands-on work as part of the **Databricks 14 Days AI Challenge**, organized by **Indian Data Club** in collaboration with **Databricks** and **Codebasics**.

The challenge is designed to build strong foundations in **Apache Spark**, **Databricks Lakehouse**, and **data engineering / analytics workflows**, progressing from fundamentals to practical, real-world use cases.

---

## 📌 Challenge Objectives

- Understand **why Databricks exists** and where it fits in modern data architectures  
- Learn **Apache Spark internals** (Driver, Executors, DAG, Lazy Evaluation)  
- Work with **DataFrames and SQL** instead of low-level RDDs  
- Practice **Databricks-native workflows** using Serverless compute  
- Apply concepts through **hands-on notebooks**, not just theory  

---

## 🧠 Key Concepts Covered

### Apache Spark Fundamentals
- Spark Architecture: **Driver, Executors, Tasks, Stages**
- DAG (Directed Acyclic Graph) execution model
- Lazy evaluation: transformations vs actions
- Shuffles and why `groupBy` is expensive

### Databricks Platform
- Databricks Workspace & Repos
- Serverless Compute limitations and best practices
- `%python`, `%sql`, `%fs` magic commands
- Databricks SQL & notebook-based analytics

### Data Engineering & Analytics
- DataFrames vs RDDs (and why DataFrames are preferred)
- Aggregations, filtering, and sorting at scale
- Caching for performance optimization
- Writing and reading **Delta Lake** tables
- SQL + PySpark interoperability

---

## 🧪 Hands-On Work Highlights

Some of the practical work included:

- Creating and running PySpark notebooks in Databricks
- Exploring Spark execution plans using `explain()`
- Performing real-world analytics on event-based datasets
- Identifying **top brands**, **category-level revenue**, and **user behavior**
- Demonstrating **lazy evaluation** and **cache reuse**
- Persisting results using **Delta format**
- Version-controlling notebooks using **Databricks Repos + GitHub**
